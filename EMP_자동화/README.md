# EMP 자동화 (pywinauto 버전)

pywinauto를 사용한 간단하고 효율적인 EMP 자동화 도구

## 🚀 설치 및 설정

1. **환경 설정**:
   ```bash
   setup_pywinauto.bat
   ```

2. **가상환경 활성화**:
   ```bash
   pywinauto_env\Scripts\activate
   ```

## 🎯 주요 특징

- **pywinauto 사용**: Windows 애플리케이션 제어에 최적화
- **간단한 구조**: 복잡한 기능 없이 핵심만
- **안정적인 동작**: GUI 요소를 정확하게 식별
