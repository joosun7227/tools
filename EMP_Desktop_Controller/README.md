# EMP 데스크탑 컨트롤러

난소프트 EMP (Enhanced Management Plus) 프로그램을 데스크탑에서 쉽게 제어하고 자동화할 수 있는 도구입니다.

## 주요 기능

### 🚀 프로그램 제어
- **EMP 시작/종료/재시작**: 원클릭으로 EMP 프로그램을 제어
- **프로세스 모니터링**: 실시간으로 EMP 실행 상태 확인
- **자동 상태 업데이트**: 주기적으로 프로그램 상태 확인

### 🪟 창 조작
- **창 최대화/최소화/복원**: EMP 창 크기 조절
- **창 위치 조정**: 사용자 정의 위치와 크기로 창 이동
- **창 찾기 자동화**: EMP 창을 자동으로 감지하고 제어

### 🤖 자동화 기능
- **자동 로그인**: EMP 시작 후 자동으로 로그인 수행
- **자동 새로고침**: 설정된 간격으로 자동 새로고침
- **스케줄 작업**: 반복 작업 자동화

### 📊 모니터링 및 로깅
- **실시간 로그**: 모든 작업 내역을 실시간으로 표시
- **상태 표시**: 현재 EMP 상태를 한눈에 확인
- **설정 저장**: 사용자 설정을 자동으로 저장/복원

## 설치 방법

### 1. 자동 설치 (권장)
```bash
# 의존성 자동 설치
install_dependencies.bat
```

### 2. 수동 설치
```bash
# Python 패키지 설치
pip install -r requirements.txt
```

### 필요한 패키지
- `psutil`: 프로세스 관리
- `pyautogui`: 마우스/키보드 자동화
- `pywin32`: Windows API 접근
- `Pillow`: 이미지 처리

## 사용 방법

### 프로그램 시작
```bash
# 배치 파일로 실행 (권장)
run_emp_controller.bat

# 또는 직접 Python 실행
python emp_controller.py
```

### 기본 사용법
1. **프로그램 시작**: "EMP 시작" 버튼 클릭
2. **상태 확인**: 상단의 상태 표시창에서 현재 상태 확인
3. **창 조작**: 필요에 따라 창 크기/위치 조정
4. **자동화 설정**: 체크박스를 통해 자동 기능 활성화
5. **로그 확인**: 하단 로그창에서 모든 작업 내역 확인

### 고급 설정
- **설정 버튼**: 창 위치, 크기 등 세부 설정 조정
- **자동 로그인**: EMP 시작 후 자동으로 로그인 수행
- **자동 새로고침**: 설정된 간격으로 화면 새로고침

## 설정 파일

프로그램은 `emp_config.json` 파일에 설정을 저장합니다:

```json
{
  "auto_start": false,
  "check_interval": 5,
  "window_position": {
    "x": 100,
    "y": 100
  },
  "window_size": {
    "width": 1200,
    "height": 800
  },
  "automation_settings": {
    "auto_login": false,
    "login_delay": 3,
    "auto_refresh": false,
    "refresh_interval": 30
  }
}
```

## 문제 해결

### 일반적인 문제
1. **EMP 프로그램을 찾을 수 없음**
   - EMP 설치 경로 확인
   - 프로그램 경로가 올바른지 확인

2. **창 조작이 작동하지 않음**
   - pywin32 패키지 설치 확인
   - 관리자 권한으로 실행 시도

3. **자동화 기능 오류**
   - pyautogui 패키지 설치 확인
   - 화면 해상도 및 DPI 설정 확인

### 로그 파일
- `emp_controller.log`: 모든 작업 내역이 기록됨
- 문제 발생 시 로그 파일을 확인하여 원인 파악
